# Demo 合集：Skill 前后效果

这三组 demo 用来测试 narrative-product-design skill 是否能在不同语境里工作：

- `01-ai-habit-coach.md`：个人成长产品，重点验证长期关怀与失败语气。
- `02-team-bug-tracker.md`：团队工具，重点验证隐喻如何服务协作效率。
- `03-personal-finance.md`：敏感场景，重点验证叙事化不能牺牲清晰和尊重。

## 观察结论

1. 好的叙事不是让文案变长，而是让每个关键节点像来自同一个世界。
2. 越敏感的场景，越要让隐喻退后，让事实和下一步站在前面。
3. 叙事方向必须能延展到空状态、错误、成功、里程碑、提醒和设置页，否则只是一个首屏概念。
4. 自动评分很有用，因为它会迫使 AI 解释为什么某个“有趣”的方向不适合长期使用。
